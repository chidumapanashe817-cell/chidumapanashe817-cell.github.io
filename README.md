# Panashe Chiduma Engineering Portfolio

This folder contains a complete static portfolio website ready for GitHub Pages.

## Files

- `index.html` – website content
- `style.css` – design and mobile responsiveness
- `script.js` – navigation, dark mode, and scroll animations
- `assets/engineering-orbit.svg` – hero illustration
- `assets/Panashe_Chiduma_Resume.pdf` – replace this placeholder with your actual resume

## Publish with GitHub Pages

1. Create a GitHub account.
2. Create a public repository named `yourusername.github.io`.
3. Upload all files and folders from this package.
4. Open the repository's **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/root` folder.
8. Save.

Your site will appear at:

`https://yourusername.github.io`

## Important edits before publishing

Open `index.html` and replace:

- The placeholder LinkedIn URL
- The placeholder GitHub URL
- Any wording or project details you want to change

Replace `assets/Panashe_Chiduma_Resume.pdf` with your real resume PDF while keeping the same filename.
